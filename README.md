# Customer-Churn-Analysis
# Customer Churn Analysis Dashboard | Power BI

## Project Overview
This project focuses on Customer Churn Analysis using Microsoft Power BI.

The objective is to analyze customer-related data and present insights through an interactive dashboard.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- Microsoft Excel / CSV
- Dax Measures
- Data Visualization
- Data Analysis

## Dataset Information
- Dataset Name: Customer-Churn-Records.csv
- Total Records: 10,000
- Total Columns: 10

### Dataset Columns
- RowNumber
- CustomerId
- Surname
- CreditScore
- Geography
- Gender
- Age
- Tenure
- Balance
- NumOfProducts

## Project Files
- Customer Churn Analysis.pbix - Power BI dashboard file
- Customer-Churn-Records.csv - Dataset used in the project
- Screenshots - Dashboard previews

## How to Use
1. Download the repository.
2. Open the PBIX file using Microsoft Power BI Desktop.
3. If required, update the dataset source path.
4. Refresh the data to explore the dashboard.
