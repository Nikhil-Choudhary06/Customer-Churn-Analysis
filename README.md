# 📊 Customer Churn Analysis Dashboard | Power BI

## 📌 Project Overview

This project focuses on Customer Churn Analysis using Microsoft Power BI. The dashboard provides an interactive view of customer information, financial balances, credit scores, geography, age groups, and product usage.

The objective is to analyze customer data, identify customer-related patterns, and present important business metrics through interactive visualizations.

## 🎯 Project Objectives

- Analyze the overall customer base.
- Understand customer balance distribution across different countries.
- Compare total balances based on the number of products.
- Analyze customer balances across different age groups.
- Explore customer data using interactive filters.
- Present key business metrics through an interactive dashboard.

## 📂 Dataset Information

**Dataset:** Customer-Churn-Records.csv

The dataset contains 10,000 customer records and customer-related information.

The dataset includes fields such as:

- CustomerId
- Surname
- CreditScore
- Geography
- Gender
- Age
- Tenure
- Balance
- NumOfProducts

## 📊 Dashboard Features & Visualizations

### 1. Total Balance by Number of Products and Geography
Compares customer balances across France, Germany, and Spain based on the number of products.

### 2. Country Wise Total Balance
Displays the distribution of total customer balance across different countries using a doughnut chart.

### 3. Total Balance by Age Group
Visualizes customer balance distribution across different age groups.

### 4. Interactive Filters
The dashboard includes interactive slicers for:
- Age Group
- Tenure
- Gender

These filters allow users to explore customer data from different perspectives.
